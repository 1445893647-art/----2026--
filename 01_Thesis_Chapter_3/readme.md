# 大论文第三章：存在合法用户的无人机反隐蔽通信方案支撑代码

## 1. 简介

本代码是学位论文第三章的支撑代码。主要实现了无人机辅助隐蔽通信场景下的**交替优化 (Alternating Optimization, AO)** 算法。代码通过联合优化无人机的干扰功率与三维飞行轨迹，在满足合法用户通信质量 (QoS) 和检测错误概率约束的前提下，最小化非法隐蔽通信的中断概率。算法利用连续凸近似 (SCA) 技术处理非凸的避让约束，并利用 Lambert W 函数求解功率优化的闭式解。

## 2. 环境配置

* **编程语言**：MATLAB 2021a / MATLAB 2021b
* **核心依赖工具箱**：
  * **CVX Toolbox**：必需依赖。用于求解轨迹优化子问题 `solve_traj_subproblem.m` 中的凸近似问题（建议配置 Mosek 或 SDPT3 求解器）。
  * **Optimization Toolbox**：建议预装，用于辅助基础优化运算。

## 3. 文件结构说明

### 核心算法与全局配置
* `main.m`：主程序入口。负责初始化系统参数与无人机状态，生成带高斯误差的位置坐标，并执行交替优化 (AO) 主循环，交替迭代直至变量收敛。
* `config_params.m`：全局参数配置文件。集中管理物理场景坐标（如 Alice、Bob、LT、LR）、通信物理参数（路径损耗 α_0、信道增益 β_0）、算法超参数及位置估计误差方差 ε。

### 子问题求解器
* `solve_power_subproblem.m`：干扰功率优化子问题求解器。在轨迹固定条件下计算最优干扰功率 P_UAV，实现基于 Lambert W 函数的闭式解。
* `solve_traj_subproblem.m`：飞行轨迹优化子问题求解器。在功率固定条件下优化无人机三维坐标，采用连续凸近似 (SCA) 处理合法用户避让非凸约束，并调用 CVX 求解。

### 性能计算与基线对比方案
* `calc_outage_prob.m`：性能指标计算函数。根据无人机当前轨迹与功率，利用真实位置计算非法隐蔽通信的中断概率 P_out。
* `get_fixed_trajectory.m`：基线轨迹生成脚本。生成从起点直飞非法接收者 Bob 上方的直线轨迹，对应论文中的固定轨迹 (Fixed Trajectory, P&NT) 方案。
* `solve_power_no_lu.m` & `solve_traj_no_lu.m`：无合法用户约束的对照求解器。移除关于合法用户速率 R_LR 的限制，用于生成极端激进的对比数据。

### 可视化与参数分析脚本
* `plot_results.m`：基础结果可视化脚本。运行后生成收敛曲线、三维空间飞行避让轨迹及逐时隙性能曲线。
* `plot_epsilon_effect.m`：检测约束敏感性分析脚本。遍历不同的检测错误概率约束 ε（0.05 ~ 0.30），绘制其对平均中断概率的影响曲线。
* `run_comparison_no_lu.m`：对比仿真出图脚本。运行无合法用户约束方案，并与主算法进行速率性能绘图对比。

## 5. 如何运行

1. 配置好 MATLAB 2021 运行环境，并确保 **CVX 工具箱** 已安装且被添加至系统路径 (Add to Path)。
2. 打开 MATLAB，将工作目录 (Current Folder) 切换至本工程根目录下。
3. 在命令行窗口直接输入 `main` 并回车，启动算法主优化流程。
4. 待命令行提示优化结束、变量收敛后，直接在命令行输入 `plot_results` 即可生成对应的彩色论文图表。
